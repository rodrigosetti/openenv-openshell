# v0.1.1 — restricted single-tenant alpha

This is the restricted single-tenant alpha prepared for PyPI publication. It retains the
scope, operator acknowledgement, cleanup limitation, and unsupported-use
boundaries documented for the v0.1.0 release candidate.

## Release fix

- The artifact SDK-prerequisite verification now explicitly acknowledges the
  restricted-alpha automatic-cleanup requirement before exercising the intended
  missing-SDK diagnostic. This makes the protected publishing workflow verify
  the same fail-closed behavior that the shipped provider requires.

## Boundaries that remain

- Use only an exclusive, trusted single-tenant OpenShell gateway and workspace.
- Shared or multi-tenant gateways/workspaces are unsupported.
- Automatic cleanup is not atomic; operators must explicitly acknowledge that
  residual risk before start or cleanup. M2, M3, I14, and SEC8c remain open.
- This package is not endorsed, certified, or supported by OpenEnv or NVIDIA.
